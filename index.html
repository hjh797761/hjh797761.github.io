Research interests

I study mathematics at USTC and am interested in how machine learning systems use past information. In large language models, I am particularly interested in how attention and memory mechanisms affect what a model can recall from its context.

Two related questions interest me: how should an AI agent decide what to remember across tasks, and how can test-time training help a model adapt to new inputs?

Selected projects

Lightweight Evidence Association Assistant

A local search tool for Chinese-language documents that combines dense retrieval with BM25 using reciprocal rank fusion. It returns source passages and can include a referenced section or a neighboring passage so readers can inspect the evidence in context.
