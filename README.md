# Academic homepage of jiahong han

Open `index.html` in a browser to preview the site. Edit that file to update the profile, research interests, project descriptions, and contact details. Keep the visible email address and its `mailto:` link in sync. Typography and responsive layout are in `style.css`.

To add publications, preprints, or research experience, add a section in `main` following the structure of Selected projects, then link to its ID from the navigation. A CV can be linked directly to a PDF in this repository.

The GitHub Pages publishing source for this layout is the root of the `main` branch.
